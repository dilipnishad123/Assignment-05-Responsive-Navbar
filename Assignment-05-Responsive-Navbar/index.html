Responsive Flexbox Navigation Bar

This navigation bar leverages modern CSS3 Flexbox for distribution and spacing.

🖥️ Desktop Layout

Menu items are arranged horizontally across the main axis with smooth hover underlines, color shifts, and active state indicators.

📱 Mobile Stacking

On screens below 768px, the menu converts smoothly into a clean vertical stacked drawer with zero JavaScript required!

✨ Pure CSS State

Utilizes semantic <nav>, accessible anchor tags, CSS transition animations, and pseudo-classes (:hover, :active, ::after).
